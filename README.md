# InterviewLARP

An interactive interview simulator built for LarpHacks.

## Overview

InterviewLARP lets users step into the role of an interviewer and practice interviewing AI-simulated candidates.

Users can provide a job description, interview three different candidates, choose questions across three rounds, and receive feedback on their interviewing decisions.

## Planned Features

- Optional job description input and analysis
- Three simulated candidates with different personalities and abilities
- Three rounds of interview questions
- Five-minute interview timer per candidate
- Interview performance score from 1–100
- Feedback and retry functionality
